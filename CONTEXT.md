# Korting Scanner

Tracks a personal list of supermarket and drugstore products across stores and reports which ones are on bonus.

## Language

**Saved product**:
A store product the user has chosen to track for bonus.
_Avoid_: Watched product, favourite

**Product group**:
A user-chosen label that bundles interchangeable saved products (across stores) so they can be compared by unit price.
_Avoid_: Category (that is the store's own classification)

**Paused**:
A saved product the user does not need for now: it is still tracked, but its bonus is not reported until the user resumes it.
_Avoid_: Snoozed, muted, disabled, inactive
